  ① 书卡上的「⋯」按钮已去掉，界面恢复干净。手机端**长按书卡约半秒**
     弹出操作菜单（打开阅读 / 重命名 / 设置封面 / 调整分类… / 移出全部分类 /
     导出原始文件 / 删除这本书），电脑上仍可点右键，拖拽到分类照旧。
     滑动超过 10px 视为滚屏不会误触；长按与系统菜单做了去重，只弹一次。
  ② 修掉「正常升级却提示安装包被篡改／请从官方安装」：上一版的签名

     安卓 assets、桌面完整性清单）全部改为**只写日志**，不弹窗、不退出。
     构建期注入的指纹和哈希仍保留在包内，代码还在，随时能恢复强度。
  ③ L2 的「重签包拒启动」硬阻断暂时关闭：误伤正版的代价远大于挡住
     破解者。这层本来就只是提高改包成本，不是加密，源码仍是明文。
  ④ 桌面 exe 不用重装：已同步 4 个文件并重生成 integrity.json，直接打开即可。

【v1.8.0 新增：像翻书一样一页一页翻 + 双击全屏】
  ① 「▤ 翻书」不再是「点一下换 6000 字」，而是按屏幕高度切成一屏一页：
     - 纸页绕书脊做 3D 旋转（rotateY 88°）+ 纸张渐变阴影，底层下一页
       从书脊一侧露出，视觉上就是翻书；老 WebView 没有 3D 时自动降级
       为横向滑动，设置里还能选「无动画」。
     - 翻页方式（四种并存）：左右滑动、点屏幕左 1/3 / 右 1/3、
       底部「上一页 / 下一页」按钮、桌面滚轮与 ← → 方向键。
     - **跨章连续填充**：短章不再各占一整页留白，下一章文字会接着排满
       当前页（parts[] 逐段记录章内绝对偏移，进度与重排都不会错）。
     - 向后翻到缓存末尾自动续下一段 / 下一章，向前翻出缓存会自动补回
       上一段 / 上一章，不用回目录。
     - 测量用离屏容器二分找每页最大可容纳字符数，留 20px 余量，
       **宁可留白也绝不裁字**；页间字符连续性由自检逐段校验。
  ② **双击正文 = 进入 / 退出全屏**，两种阅读方式都生效。
     - Android WebView 通常不派发 dblclick（双击被缩放手势吞掉），
       所以自己按 click 的时间戳 + 位移判定，单击翻页延迟 360ms，
       双击会取消那次待执行的单击，不会误翻页。
     - Java 里关掉了双击缩放（setSupportZoom(false)），保证第二次 click
       能送到页面。
     - 全屏 / 横竖屏 / 改字号 / 改行距后，正文高度变了会**自动重新分页**
       并按「缓存全文字符序号」回到原来那一页，不会跑位、不会裁字。
  ③ 工具条按钮文案「⇅ 连续 / ▤ 翻书」，设置里新增「翻书动画」三档
     （仿真 / 滑动 / 无动画）和全屏说明。连续滚动模式完全保留原样。
  ④ 扫描版 PDF 仍走原来的图片流，不套书页。

    而书库存在 App 内 IndexedDB，卸载 = 书全没。已额外备份到：
        安卓\_签名备份\debug.keystore
        PC\_签名备份-debug.keystore

【实现原理】
    compat.js            ES5 运行时补丁（含纯 JS SHA-256），最先加载
    android-storage.mjs  IndexedDB 实现同一组 StorageBackend 方法
    api-bridge.mjs       覆盖 window.fetch，把 /api/* 直接调 LibraryApp
    bootstrap.mjs        先装桥再加载 app.js；封面转 blob、导出桥
    shell.js             手机导航壳 + 启动自检 + 返回键（ES5 classic）
    bundle.js            esbuild 产物：全部模块 + app.js + core，ES2016 IIFE
    vendor/fflate.mjs    纯 JS DEFLATE，替代老 WebView 没有的 DecompressionStream
    mobile.css           手机布局（顶栏 / 底栏 / 抽屉 / 沉浸 / 安全区 / 多档屏）
    MainActivity.java    虚拟 https origin、文件选择、导出保存、外链接管、
                         返回键、状态栏主题、ROM 兼容、应用内更新、
                         匿名统计心跳（SharedPreferences + 12h 节流）、禁双击缩放
    ApkProvider.java     零依赖 FileProvider 等价物（工程没有 androidx），
                         只把 files/apk/update.apk 以 content:// 交给系统安装器
  顶栏与底栏只是「转发点击」到桌面侧栏里已有的真实按钮，没有另写业务逻辑。

【已知边界】
  - 渲染验证是本机 Chromium（多视口 + 移动设备模拟 + 禁用 JS），
    **不是真机 WebView**；3D 翻页在各厂商 GPU 合成上的表现、双击手势在
    各 ROM 上的 click 派发，还需要你在 P40 上实装确认。
    装上后若异常，红色自检条截图 + adb logcat -s OpenReader 发我。
  - 应用商店渠道（软著 / 实名 / 审核）不在本方案内；本方案是自建分发。
  - 连续流只向前追加、向前裁剪，往回翻很多章需用目录重开。
  - 书页缓存末尾（还没预取到新段时）可能有一页未排满，再往后翻一次即补齐。
  - 点「打开下载」会跳夸克网盘，仍会看到 pan.quark.cn。
  - 求书到货角标不亮（只依赖桌面 Electron 的本地 IPC），求书页本身正常。
  - 使用统计只覆盖安卓 App 的上报，桌面 exe 不计入；「今日活跃」按
    匿名设备 UUID 按天去重，不是实时在线人数。站点休眠期间会缺数据。
