使用帮助

点标题展开，按步骤看。全部内容内置在应用里，断网也能查。

① 三分钟上手（看图照做）
  1. 导入：侧栏点「＋ 导入书籍」选文件，或点「＋ 导入文件夹」一次收整本书架。也能把书直接拖进窗口。
  2. 打开：在书架点封面，进入阅读；左侧目录列章节，点章节直接跳。
  3. 调舒服：顶部 A− / A＋ 调字号，「◐ 主题」切换明亮 / 护眼 / 深夜，侧栏底部「⚙ 设置」里还能调字体、行距、翻书动画。
  4. 继续读：阅读进度自动保存，下次打开同一本书接着上次的位置；「最近阅读」和「我的书签」都能快速回去。
书和进度都存在本机，不上传。换电脑或重装前，先到「设置 → 导出整库」备份一份。
② 支持哪些格式
类别格式说明
文字书TXT / MD / EPUB / DOCX / DOC / RTF / ODT / FB2 / HTML / MHTML自动识别编码与章节，推荐 TXT / EPUB
电子书MOBI / PRC / PDB / AZW / AZW3AZW3 的 HUFF/CDIC 压缩也能读
扫描版PDF图片页连续滚动，双指缩放
打包ZIP / .openlib整库包或多本书一次导入
受 DRM 加密的版权书打不开，需要先在其他工具里解除保护再导入。
③ 阅读与排版

两种阅读方式

顶部「⇅ 连续」可切换连续滚动 / 仿真翻书。设置里可选仿真 / 滑动 / 无动画，每页字数也能自己定。

章节与跳转

左侧目录列出全部章节；目录顶部输入框可按名称筛选，输入页码回车直接跳到那一页。

书签与全屏

顶部「☆ 书签」记下当前位置，侧栏「我的书签」可一键跳回。「⛶ 全屏」或 F11 进入沉浸阅读。

按键作用
→ 空格 PageDown下一页
← PageUp上一页
Ctrl / ⌘ + F聚焦搜索框
F11全屏阅读（阅读时）
Esc退出全屏 / 关闭弹窗 / 返回书架
手机上没有键盘：轻点屏幕中部唤出/隐藏工具栏，左右滑动翻页，双击正文进全屏。
④ 找书：搜索、分类、批量整理
  • 全文搜索：侧栏搜索框输入关键词，书名和正文都会命中，结果显示命中段落，点结果直接跳到那一章。
  • 排序与筛选：书架顶部可按添加时间 / 名称 / 作者 / 大小 / 最近阅读 / 格式 / 章节数排序，「全部 / 最近阅读 / 未分类」快速切换。
  • 分类：侧栏「我的书架」旁点 ＋ 新建分类；书中右键或「批量整理」可加入 / 移出分类。
  • 批量整理：书架顶部「☑ 批量整理」→ 勾选多本 → 调整分类 / 移出分类 / 删除所选，支持全选和反选。
删除的书会从书架消失；只要没清回收站数据，仍可从整库备份里找回。
⑤ 备份、迁移与误删
  • 电脑版：所有数据都在「书库目录」（侧栏最下方显示路径）。设置 → 导出整库，打包成 .openlib；换电脑时把整个目录拷过去，或导入这个包。
  • 安卓版：书库在本机私有存储，文件管理器看不到。设置 → 导出整库备份 / 从备份恢复，可自己起名字、选保存位置。
  • 重建索引：书架顶部「重建索引」，全文搜索失效或导入后搜不到时点一下。
  • 误删：先用最近的整库备份恢复；覆盖恢复会清空现有书库，想保留现有内容请先导出一份当前备份。
卸载应用会清空书库数据，重装前务必先导出整库备份。
⑥ 云书库、求书与反馈
  • 云书库：侧栏「☁ 云书库」，搜站内已有书籍，搜到即可打开下载，只有点开这一页时才联网。
  • 求书：侧栏「✎ 求书」提交书名，找到后侧栏红点提醒。管理端填入的书籍链接会自动同步到书库，书库只增不减。
  • 意见反馈：设置 → 意见反馈，匿名提交，只在点开时联网。反馈页带版本号，方便定位问题。
  • 检查更新：安卓版在设置 → 应用更新 → 检查更新；发现新版会提示下载安装。
断网时这些功能会提示加载失败，本地书架和阅读完全不受影响。
⑦ 常见问题排查
现象怎么处理
书打不开 / 提示格式不支持确认格式在「支持哪些格式」列表里；加密的 DRM 书不支持；用书架顶部「重建索引」后再试。
打开是乱码多为无 BOM 的 GBK 文本，删除后重新导入让引擎重新识别编码；或先在编辑器里另存为 UTF-8。
搜不到内容书架顶部「重建索引」；全文搜索只索引文字书，扫描版 PDF 的图片内容搜不到。
目录为空或章节不对TXT 按常见「第X章」标题识别，非标准标题可能不拆分；EPUB / AZW3 用文件自带目录。
打开很慢 / 卡住超大部头首次解析会慢一些，等进度条走完；关闭「仿真翻书」动画可减轻负担。
云书库 / 求书空白检查网络；反馈页只在你点开时联网，断网时不影响本地阅读。
以上都不行时，到「设置 → 意见反馈」说明书名、格式和具体现象，并带上版本号。
